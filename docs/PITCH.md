# Pitch (4 min + 3 min Q&A)

**One-liner:** WebScope is solving ___ for ___. Our solution is ___.

## Judging (25 pts)
- Problem + user
- Solution + feasibility
- Technical innovation (our own design vs. off-the-shelf)
- Validation (does it work, did users try it)
- Impact

## Flow
| Time | Who | Slide |
|---|---|---|
| 0:00 | Dominique | One-liner |
| 0:20 | Dominique | User + problem |
| 0:50 | Dominique | Solution + live demo |
| 1:30 | Nick | How it works (FPGA) |
| 2:20 | Dominique | Validation |
| 2:50 | Dominique | Competition + cost |
| 3:20 | Dominique | Impact + roadmap |
| 3:45 | Dominique | Ask / close |

## Notes
- No sound in slides; GIFs over video. Backup demo GIF.
- Real prices, real test numbers, real user quotes.
- Timed practice runs.
